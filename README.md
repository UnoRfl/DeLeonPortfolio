# Lil Romeo De Leon — Portfolio

A responsive static portfolio for Lil Romeo De Leon, a BSIT-GD student at the University of Perpetual Help System DALTA. The visual direction carries the reference site's charcoal, warm-metal palette, clay surfaces, and page transitions into its own editorial split hero and inspiration gallery.

## Pages

- /home/ — filterable image gallery with a click-to-enlarge viewer
- /about/ — introduction, learning goals, and skills in progress
- /contact/ — email, phone, course, and school

The site is built with plain HTML, CSS and JavaScript. It has no build step. GitHub Pages serves the main branch from the repository root.

The gallery is a credited inspiration collection, not a claim that the photographs or renders are Lil Romeo's original projects. See CREDITS.md for image creators, source pages, and licenses. The portrait is a retouched image based on a photo provided for this portfolio.
